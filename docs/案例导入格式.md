# 案例导入格式说明

导入入口：案例选择页 →「＋ 导入案例」。支持一次上传一个 Word/PPT 加若干图片。

## 支持的文件

| 类型 | 扩展名 | 说明 |
|---|---|---|
| Word | `.docx` / `.doc` | `.doc` 会自动转换成 `.docx` 再解析 |
| PowerPoint | `.pptx` / `.ppt` | `.ppt` 会自动转换成 `.pptx` 再解析 |
| 图片 | `.png` `.jpg` `.jpeg` `.webp` `.gif` `.bmp` `.tif` | 单独上传时生成一幕「图像资料」 |

限制：一次最多 10 个文件，总大小不超过 20MB。

## 幕次标题怎么写

解析器按标题机械切分，不会用 AI 猜结构。以下写法都能识别：

```text
第一幕 · 就诊
第二幕：查体与检查
第3幕 确诊
【第四幕】转归
幕五
Act 1: Chief Complaint
Scene 2
```

Word 里没有「第 X 幕」标题时，会退化为按 `Heading 1 / 标题 1` 段落切分；如果连标题样式也没有，整篇文档作为 1 幕导入（预览会提示）。

PPT 里没有幕次标题时，每个有内容的幻灯片作为一幕；首页只有标题时视为案例封面。

## 栏目怎么写

栏目标题单独成行，后面跟列表即可。支持中英文冒号。

### 学习目标（案例级）

```text
学习目标：
- 掌握急腹症的问诊重点
- 理解转移性腹痛的机制
```

### 讨论问题（幕级）

```text
讨论问题：
1. 从主诉中能提取哪些关键信息？
2. 还需要补充什么查体？
```

### 助教参考（幕级，不会展示给学生）

```text
助教参考：
期望假设：
- 急性阑尾炎
- 急性胃肠炎
期望议题：
- 疼痛转移的解剖机制
- 腹膜刺激征的病理基础
```

「助教参考」下没有归类的行会保存到 `tutor_notes.notes`，不影响导师逻辑，也不会出现在学生界面。

### 最终诊断 / 关键学习点（通常放最后一幕）

```text
最终诊断：急性化脓性阑尾炎（局限性腹膜炎）

关键学习点：
- 转移性右下腹痛的机制
- 腹膜刺激征的判断
```

## 图片

- **Word**：内嵌图片按在文档中的位置归入当前幕；表格里的图片也会提取。
- **PPT**：幻灯片上的图片归入该页对应的幕。
- **单独上传**：如果同时上传了 Word/PPT，图片会追加为最后一幕「图像资料」；如果只传图片，会生成一个图片案例。
- 单张图片超过 8MB 会跳过；EMF/WMF 等浏览器不支持的格式会跳过。

## PPT 演讲者备注

只提取备注里明确写了「讨论问题」「助教参考」「最终诊断」「关键学习点」的内容。  
其他备注不会进入学生界面（避免答案泄露），预览里会提示忽略了几页备注。

## 导入后

上传后会先显示预览：案例标题、幕数、每幕摘要、图片缩略图和警告。  
确认后案例入库，出现在案例列表中（带「导入」标识），之后可正常开始讨论、使用语音导师和导出纪要。

当前版本不支持在线编辑已导入案例；如果解析结果不满意，修改源文件后重新导入即可。
